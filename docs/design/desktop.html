Configuração de dados

A aplicação começa em Demo. As futuras API keys são guardadas pela camada nativa. O estado “configurado” é diferente de uma ligação verificada.

Um score explicável

Qualidade, crescimento, valuation, momentum e risco têm origens e cobertura visíveis. O score é heurístico; não é uma ordem de compra. Os números desta proposta são ilustrativos.

Quando falta contexto

TSM tem cotação no exemplo, mas apenas três das nove métricas do modelo. Mostramos o que existe e deixamos o score indisponível. O movimento do preço não preenche fundamentais em falta.

Este é um cenário de demonstração, sem pedidos a providers.
