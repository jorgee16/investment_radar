Providers & routing

Testar ligação

Guarda primeiro as chaves. O teste pede uma cotação real a cada provider configurado, mesmo em modo Demo. Não valida as restantes permissões do plano.

API KEYS

Live provider credentials

native storage

As chaves são guardadas pela camada nativa e não são devolvidas à interface. No Windows usa-se DPAPI; no Android, Keystore. Chaves do ambiente cloud são lidas sem as copiar para o ficheiro local.

ROUTING

Preferred source by data type

routing

Automático tenta os providers configurados com a capacidade pedida. Em Live, dados demo nunca são usados como fallback.

Onde obter as chaves

EODHD

Abre eodhd.com/register, cria a conta e copia o API Token no dashboard da conta.

Para ações europeias, confirma a bolsa e o acesso a cotações, histórico e fundamentais no plano.

Financial Modeling Prep

Abre site.financialmodelingprep.com, cria a conta e procura a API Key no Dashboard.

Acesso internacional, demonstrações e endpoints Stable dependem do plano.

Twelve Data

Abre twelvedata.com, cria a conta e copia a chave em Dashboard → API Keys.

Usado para cotações e histórico. Confirma bolsas europeias e os créditos do plano.

Alpha Vantage

Obtém uma API key em alphavantage.co.

Enriquecimento opcional; as quotas gratuitas são limitadas.

Finnhub

Obtém uma API key em finnhub.io.

Enriquecimento opcional; verifica as permissões do plano.

Cola cada chave no campo correspondente, escolhe Live, guarda e testa. Basta um provider com os dados de que precisas para começar. Não é necessário subscrever todos os providers.
