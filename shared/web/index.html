Onde obter as chaves

EODHD

Abre eodhd.com/register, cria a conta e copia o API Token no dashboard da conta.

Para ações europeias, confirma a bolsa e o acesso a cotações, histórico e fundamentais no plano.

Financial Modeling Prep

Abre site.financialmodelingprep.com, cria a conta e procura a API Key no Dashboard.

Acesso internacional, demonstrações e endpoints Stable dependem do plano.

Twelve Data

Abre twelvedata.com, cria a conta e copia a chave em Dashboard → API Keys.

Usado para cotações e histórico. Confirma bolsas europeias e os créditos do plano.

Cola cada chave no campo correspondente, escolhe Live, guarda e testa. Basta um provider com os dados de que precisas para começar. Não é necessário subscrever os três.
